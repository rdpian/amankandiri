# 📖 Kamus Gaul Keamanan Digital

Dengar istilah teknis keamanan internet sering bikin pusing? Tenang! Di sini, istilah-istilah "keren" itu diterjemahkan ke bahasa sehari-hari yang simpel.

---

## 🔤 Istilah Populer & Artinya

### 🎣 Phishing (Pancingan Data)
* **Bahasa Gampangnya**: Umpan penipu buat memancing data pribadi kamu.
* **Contoh**: Penipu bikin website palsu yang tampilannya mirip banget sama halaman login bank atau media sosial kamu, supaya kamu mengetikkan username dan password di sana.

### 🔑 OTP (One-Time Password / Kode Rahasia Sekali Pakai)
* **Bahasa Gampangnya**: Kunci darurat berbentuk kode 4-6 angka yang dikirim lewat SMS atau WhatsApp.
* **Aturan Emas**: Kode ini cuma boleh kamu yang tahu! Pihak bank, WhatsApp, atau aplikasi apa pun **tidak akan pernah** minta kode OTP kamu.

### 🔐 2FA / MFA (Two-Factor Authentication / Otentikasi Dua Langkah)
* **Bahasa Gampangnya**: Gembok ganda untuk akun kamu.
* **Contoh**: Selain memasukkan password biasa, kamu juga diwajibkan memasukkan PIN tambahan atau kode dari aplikasi keamanan saat mau login di perangkat baru.

### 📱 .APK (File Aplikasi Android)
* **Bahasa Gampangnya**: Mentahan installer aplikasi untuk HP Android.
* **Bahayanya**: Kalau kamu download aplikasi resmi dari Play Store, itu aman. Tapi kalau ada orang asing kirim file `.apk` lewat WhatsApp (misal: "Foto_Paket.apk"), itu hampir pasti program jahat!

### 👤 Identity Theft (Pencurian Identitas)
* **Bahasa Gampangnya**: Orang lain pura-pura jadi kamu.
* **Contoh**: Penipu mengambil foto dan nama kamu dari media sosial, lalu bikin akun palsu buat pinjam uang ke teman-temanmu.

### 👁️ Social Engineering (Manipulasi Psikologis)
* **Bahasa Gampangnya**: Trik bikin korban panik, tergiur, atau buru-buru sampai lupa berpikir jernih.
* **Contoh**: Dikabarkan dapat hadiah miliaran rupiah (bikin tergiur) atau dikabarkan keluarga kecelakaan (bikin panik).

### 💳 Quishing (QR Code Palsu)
* **Bahasa Gampangnya**: Penipuan pakai stiker QR Code/QRIS.
* **Contoh**: Penipu menimpa stiker QRIS resmi di meja kasir atau kotak amal dengan stiker QRIS milik mereka sendiri.

## 💡 Ringkasan Cepat

| Istilah Keren | Bahasa Sehari-hari | Yang Harus Kamu Lakukan |
| :--- | :--- | :--- |
| **Phishing** | Link/Web Palsu | Jangan asal ketik password di link asing. |
| **OTP** | Kunci Rahasia SMS | Sifatnya rahasia, jangan kasih ke siapa pun! |
| **2FA** | Gembok Ganda | Selalu aktifkan di WhatsApp & Email. |
| **File .APK** | Aplikasi Gelap | Wajib abaikan kalau dikirim via WhatsApp. |
