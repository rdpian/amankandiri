## 💡 3 Aturan Emas Keselamatan Digital

Jika harus mengingat 3 hal saja dari panduan ini, ingatlah prinsip ini:

1. **Jangan Asal Klik / Install**: Jangan pernah membuka file berakhiran `.apk` dari WhatsApp atau mengklik link asing dari orang yang tidak dikenal.
2. **Rahasiakan Kode Kunci**: Kode OTP (SMS), PIN, dan Password itu seperti kunci rumah. Jangan pernah berikan ke siapa pun, termasuk pihak yang mengaku petugas bank.
3. **Tetap Tenang & Verifikasi**: Penipu selalu membuat korban panik atau terburu-buru. Jika menerima kabar darurat, selalu tutup telepon dan hubungi nomor resmi keluarga/instansi terkait terlebih dahulu.
