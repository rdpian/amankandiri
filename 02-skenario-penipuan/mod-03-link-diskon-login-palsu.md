# 🔗 Modus Link Diskon & Web Login Palsu (Phishing)

Modus ini bertujuan menjebak kamu agar secara sukarela mengetikkan kata sandi, PIN, atau data kartu kredit di situs web palsu yang dibuat sangat mirip dengan versi aslinya.

---

## 🎭 Skenario Cerita (Bagaimana Ini Terjadi?)

1. **Umpan Menarik**: Kamu menerima SMS, pesan WhatsApp, atau melihat iklan di media sosial berisi tawaran yang menggiurkan:
   * *"Selamat! Anda mendapatkan hadiah voucher belanja Rp1.000.000 dari Tokopedia. Klaim di sini: bit.ly/promo-diskon"*
   * *"Peringatan: Akun Instagram Anda akan ditutup dalam 24 jam karena pelanggaran hak cipta. Verifikasi di: instagram-support-security.com"*
   * *"Promo kuota internet gratis 100 GB dari pemerintah, klik link ini untuk mengaktifkan."*
2. **Kunjungan Web Palsu**: Saat link diklik, kamu diarahkan ke halaman yang tampilan visual, logo, dan warnanya persis seperti situs asli.
3. **Pencurian Data**: Situs tersebut meminta kamu memasukkan nama pengguna, kata sandi, kode OTP, atau nomor kartu debit/kredit untuk klaim hadiah. 
4. **Hasilnya**: Setelah kamu menekan tombol "Kirim", data login kamu langsung masuk ke komputer penipu.

---

## 🔍 Ciri-Ciri Utama Penipuan Ini

* **Alamat Web (URL) Aneh**: Perhatikan tulisan di baris paling atas browser HP kamu.
  * *Asli*: `instagram.com` atau `tokopedia.com`
  * *Palsu*: `instagram-verifikasi.xyz`, `tokoped1a-promo.com`, atau menggunakan penyingkat link gratis seperti `bit.ly` / `tinyurl.com`.
* **Iming-Iming Terlalu Bagus**: Mendapatkan hadiah besar tanpa alasan yang jelas atau tanpa pernah mengikuti undian.
* **Menakut-nakuti**: Menggunakan ancaman seperti *"Akun diblokir jika tidak verifikasi sekarang"*.

---

## 🛡️ Cara Mencegahnya

1. **Selalu Cek Alamat Web (URL)**: Jangan cuma melihat tampilan halamannya, tapi periksa ejaan alamat domainnya di bagian atas browser.
2. **Jangan Login Lewat Link Kiriman**: Jika ada pemberitahuan dari aplikasi (seperti Tokopedia, Bank, atau Instagram), lebih baik buka aplikasi resminya langsung, bukan mengklik link dari SMS/WA.
3. **Gunakan Pengelola Kata Sandi (Password Manager)**: Browser modern (seperti Chrome atau Safari) biasanya tidak mau mengisi otomatis kata sandi kamu jika mendeteksi situs tersebut palsu.

---

## 🆘 Apa yang Harus Dilakukan Kalau Terlanjur Ketik Data di Web Palsu?

Jika kamu terlanjur memasukkan kata sandi atau data sensitif di web tersebut:

1. **Ganti Kata Sandi Seketika**: Segera buka aplikasi asli (misal: Instagram/M-Banking) dan ubah password kamu detik itu juga sebelum penipu sempat mengambil alih.
2. **Keluarkan Semua Sesi Login**: Masuk ke menu keamanan aplikasi, pilih opsi **"Keluar dari Semua Perangkat"** (*Log out of all devices*).
3. **Aktifkan Verifikasi 2 Langkah (2FA)**: Jika belum aktif, segera nyalakan fitur gembok ganda ini di aplikasi kamu.
4. **Blokir Kartu (Jika Memasukkan Data Kartu)**: Jika kamu sempat memasukkan nomor kartu ATM/kredit, segera hubungi bank untuk memblokir kartu tersebut.
